# MarkItBetter — สารบัญที่เสนอ

สำหรับนักพัฒนาและผู้ใช้ที่คุ้นเคยกับ Markdown อยู่แล้ว

ตัวอย่างสไตล์และโครงร่างบทสำหรับตรวจทาน คู่มือรุ่นเผยแพร่ v0.49.0 และตัวอย่าง Mermaid ที่พัฒนาเสร็จแล้ว

## 1. ติดตั้งและเริ่มใช้งาน

- การติดตั้ง เปิดใช้งานครั้งแรก และข้อควรทราบของแต่ละแพลตฟอร์ม
- ราคา $13 และนโยบายอัปเกรดฟรีตลอดอายุการใช้งาน

## 2. เวิร์กโฟลว์ของ MIB

- เริ่มจากโหมดอ่าน กด i เพื่อแก้ไข และ Esc เพื่อกลับมาอ่าน
- การบันทึกอัตโนมัติ ไฟล์ที่ยังไม่ตั้งชื่อ และการไปยังต้นฉบับจากพรีวิว

## 3. ไฟล์และโฟลเดอร์งาน

- เปิดและบันทึกไฟล์ แท็บ ไฟล์ล่าสุด และรายการโปรด
- เปิดไฟล์อย่างรวดเร็วและใช้ลิงก์ Markdown ภายในเครื่อง

## 4. นำทางด้วยคีย์บอร์ด

- แถบคำสั่ง สารบัญหัวข้อ และการเปิดไฟล์อย่างรวดเร็ว
- ค้นหาในพรีวิว รวมถึงค้นหาและแทนที่ในโหมดแก้ไข

## 5. แก้ไขข้อความอย่างแม่นยำ

- หลายเคอร์เซอร์ การเลือกแบบคอลัมน์ และการจัดการบรรทัด
- โหมดโฟกัส การจัดรูปแบบต้นฉบับ และการเลิกทำ

## 6. เมนู / และช่องกรอกใน snippet

- แทรกลิงก์ รูปภาพ โค้ด ตาราง และบล็อกพับเก็บได้
- ใช้ Tab และ Shift+Tab เลื่อนช่องกรอก แล้วกด Esc เพื่อจบ

## 7. จัดการตารางใน Markdown

- เพิ่มหรือลบแถวและคอลัมน์จากเมนูข้างเคอร์เซอร์
- กด Tab เพื่อเพิ่มแถว แล้วจัดรูปแบบให้ต้นฉบับเรียงตรงกัน

## 8. รูปแบบ Markdown ที่รองรับ

- งาน เชิงอรรถ ไฮไลต์ โค้ด และเนื้อหาพับเก็บได้
- ตัวอย่างที่ใช้ได้จริงและข้อจำกัดของ HTML ที่ปลอดภัย
- snippet สำหรับรูปภาพและลิงก์ รวมถึงการอ้างอิงไฟล์ในเครื่อง
- พาธ ข้อความทดแทนรูป และการแก้ปัญหาไฟล์ไม่แสดง

## 9. สร้างและอ่านแผนภาพด้วย Mermaid (ฟีเจอร์รุ่นพัฒนา)

- เขียนบล็อก Mermaid แล้วดูผลเป็นแผนภาพ
- ชื่อแผนภาพ ชื่อสำหรับการเข้าถึง และกรณีที่ไม่ได้ตั้งชื่อ
- เปิด Source พร้อมสีไวยากรณ์ใต้แผนภาพที่ยังมองเห็น
- ขยาย คืนขนาด กด Esc และรักษาโฟกัสกับตำแหน่งอ่าน
- ค้นหาในป้ายข้อความและต้นฉบับ แล้วกลับไปแก้ไข
- ชนิดแผนภาพของ Mermaid11.17.2 ชื่อเรียก และข้อจำกัดที่อนุมัติแล้ว
- ภาษาไทย ญี่ปุ่น ข้อความหลายภาษา และป้ายข้อความยาว
- ข้อผิดพลาดเฉพาะแผนภาพ ขอบเขต การกู้คืน และการแก้ปัญหา
- ตัวอย่าง flowchart, sequence, สถาปัตยกรรม และบันทึกโครงการ

## 10. พรีวิวที่เชื่อมกับต้นฉบับ

- ความกว้างพื้นที่อ่าน แผงข้อมูล ช่องทำเครื่องหมาย และตำแหน่งต้นฉบับ
- สลับอ่านและแก้ไขโดยไม่หลงตำแหน่ง

## 11. ปรับพื้นที่อ่านให้เหมาะกับคุณ

- ชุดฟอนต์พรีวิว ธีมสว่างหรือมืด และฟอนต์ในโหมดแก้ไข
- ฟอนต์ไทยมีหัวสำหรับเนื้อหา ภาษาญี่ปุ่น และสไตล์พรีวิวที่ปรับเอง

## 12. ตัวอย่างเวิร์กโฟลว์ใช้งานจริง

- README บันทึกทางเทคนิค และเช็กลิสต์ก่อนเผยแพร่
- บันทึกสถาปัตยกรรมพร้อมแผนภาพ โดยระบุสถานะการรองรับ

## 13. คู่มือคีย์ลัด

- สลับโหมด นำทาง แก้ไข ตาราง และช่องกรอกใน snippet
- ปุ่มบน macOS และปุ่มเทียบเท่าบน Windows/Linux ตามเอกสาร

## 14. แก้ปัญหาและฟีเจอร์ที่จะตามมา

- ปัญหาการบันทึก ฟอนต์ ไฟล์ในเครื่อง และการแสดงผล
- แยกฟีเจอร์ที่เผยแพร่แล้วจากฟีเจอร์ที่พัฒนาเสร็จ พร้อมข้อมูลอัปเดต
