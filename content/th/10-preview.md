# พรีวิวที่เชื่อมกับต้นฉบับ

PREVIEW เป็นพื้นที่อ่านที่โต้ตอบได้ ใช้ตามลิงก์ ค้นหาข้อความ สลับสถานะงาน และเข้า EDIT ที่ตำแหน่งต้นฉบับที่เหมาะสมได้ โดยเฉพาะเมื่อเครื่องหมาย Markdown ทำให้ต้นฉบับดูต่างจากผลลัพธ์มาก

## แก้ข้อความจากเอกสารที่จัดรูปแบบแล้ว

ดับเบิลคลิกคำที่จะเปลี่ยน โปรแกรมจะเลือกคำที่สอดคล้องกันในต้นฉบับเมื่อระบุตำแหน่งได้ หากเป็นช่องว่างหรือกรณีจับคู่ยาก อาจไปตำแหน่งต้นฉบับใกล้เคียง ตรวจช่วงเลือกก่อนแทนข้อความ

หลังแก้ กด Esc เพื่อกลับบล็อกที่เคอร์เซอร์อยู่ การยึดบล็อกคาดเดาได้ง่ายกว่าการรักษาตำแหน่ง scrollbar แบบพิกเซลระหว่างสองรูปแบบที่สูงต่างกัน โค้ดยาว เนื้อหาที่เปิดใน details หรือรูปอาจทำให้ตำแหน่งต่างกันมาก

การเข้าด้วยคีย์บอร์ดมีพฤติกรรมการเลือกเฉพาะ ดู [เวิร์กโฟลว์](workflow.html#enter-the-source-where-you-need-it) เพื่อแยกการดับเบิลคลิกคำ การเลือกแล้วกด `i` และการกด `a` เพื่อเพิ่มท้ายเอกสาร

## รายการงานที่โต้ตอบได้ {#interactive-task-lists}

```markdown
- [ ] เตรียมเผยแพร่
  - [x] ทบทวนตัวอย่าง
  - [ ] ตรวจลิงก์
```

คลิกตัวควบคุมงานใน PREVIEW เพื่อเปลี่ยน `[ ]` / `[x]` การสลับงานแม่มีผลกับงานลูกด้วย แม่อาจแสดงสถานะผสมเมื่อทำลูกบางส่วนเสร็จ สถานะนี้คำนวณจากลูก ไม่ได้เขียนเครื่องหมาย Markdown ชนิดใหม่

ใช้ [Preferences → Tasks](preferences.html#tasks) กำหนดว่าจะให้รายการที่เสร็จจางหรือขีดฆ่าหรือไม่ เป็นตัวเลือกแสดงผล ผู้ร่วมงานยังเปิดไฟล์แล้วเห็น task list มาตรฐาน GFM

## อ่านเอกสารเทคนิคยาว ๆ

ใช้ Outline กระโดดตามหัวข้อ และ Find หาวลี ลิงก์หัวข้อกับเชิงอรรถเลื่อนภายในพรีวิว พับ `<details>` เมื่อรายละเอียดรองรบกวนการอ่าน แล้วเปิดเมื่อต้องใช้ขั้นตอนจริง

ความกว้างพรีวิวคำนวณอัตโนมัติจากพื้นที่ที่เหลือ ตัวเลือกความกว้างที่กำหนดเองอยู่ได้ในช่วงที่เปิดไฟล์นั้น เมื่อเปลี่ยนไฟล์จะคืนกฎอัตโนมัติ ดู [ความกว้างเนื้อหา](appearance.html#content-width) สำหรับตัวเลือก 60% และ 90%

## ตรวจสิ่งที่ผู้อ่านจะได้รับ

กลับ PREVIEW หลังแก้โครงสร้างรายการ เชิงอรรถ ตาราง หรือ HTML wrapper สีโค้ดอาจปรากฏตามหลังเนื้อหาหลักเพราะโหลด grammar ตามใช้ ภาษาที่ไม่รู้จักควรยังอ่านแบบข้อความโค้ดธรรมดาได้

เอกสารเดียวกันอาจแสดงต่างกันในเครื่องมือ Markdown อื่น ใช้ต้นฉบับมาตรฐานเมื่อแชร์ และระบุส่วนขยายที่ทีมเลือกใช้ [Mermaid viewer ที่จะตามมา](mermaid.html) เพิ่ม Source, Find และการขยายเฉพาะแผนภาพ ซึ่งยังไม่ใช่พฤติกรรม code fence ปกติของ v0.49.0
