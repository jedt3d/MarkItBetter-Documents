# แก้ไขข้อความอย่างแม่นยำ

EDIT แสดงต้นฉบับ Markdown ทั้งเครื่องหมาย ลิงก์ และรั้วโค้ด เลือกข้อความแล้วใช้คำสั่งที่ตรงงาน จากนั้นกลับไป PREVIEW เพื่อตรวจสิ่งที่ผู้อ่านจะเห็น

## คีย์จัดรูปแบบ

เลือกข้อความแล้วกด **Command+B / Ctrl+B** เพื่อทำตัวหนา **Command+I / Ctrl+I** เพื่อทำตัวเอียง และ **Command+E / Ctrl+E** เพื่อทำ inline code กดซ้ำบนข้อความที่มีรูปแบบนั้นอยู่แล้วเพื่อเอาเครื่องหมายครอบออก **Command+K / Ctrl+K** สร้างลิงก์โดยใช้ข้อความที่เลือกเป็นชื่อ แล้วเลือกช่อง URL ให้กรอก

ใช้ **Option+Command+1…6 / Alt+Ctrl+1…6** กำหนดระดับหัวข้อ กดระดับเดิมซ้ำเพื่อยกเลิก **Command+Shift+X / Ctrl+Shift+X** สลับขีดฆ่า ส่วน **Command+Enter / Ctrl+Enter** เปลี่ยนบรรทัดเป็นงานที่ยังไม่เสร็จ งานที่เสร็จแล้ว และกลับเป็นงานที่ยังไม่เสร็จ

## เปลี่ยนหลายตำแหน่งพร้อมกัน

เลือกตัวระบุแล้วกด **Command+D / Ctrl+D** เพื่อเพิ่มตำแหน่งที่ตรงกันถัดไป หรือ **Command+Shift+L / Ctrl+Shift+L** เพื่อเลือกทุกตำแหน่งที่ตรงกัน ตรวจช่วงเลือกก่อนพิมพ์ เพราะทุกตำแหน่งที่ยังใช้งานจะเปลี่ยนพร้อมกัน

บน Mac ใช้ Option-click เพิ่มเคอร์เซอร์ และ Option-drag เลือกเป็นสี่เหลี่ยม คีย์ Alt ที่สอดคล้องกันอยู่ใน [คู่มือคีย์ลัด](shortcuts.html) ระบบเดสก์ท็อปบางชนิดอาจรับคำสั่ง Alt กับเมาส์ไปก่อนโปรแกรม การเลือกแบบคอลัมน์คาดเดาได้ง่ายขึ้นเมื่อใช้ฟอนต์โมโนและบรรทัดที่มองเห็นได้ครบ

ดับเบิลคลิกเลือกคำ ดับเบิลคลิกช่องว่างนำหน้าบรรทัดเลือกทั้งบรรทัด และคลิกสามครั้งเลือกบล็อก Markdown หากทำบนหัวข้อ จะเลือกทั้งหัวข้อและเนื้อหาจนถึงหัวข้อระดับเดียวกันหรือสูงกว่า ตรวจขอบเขตก่อนตัดข้อความจำนวนมาก

## ย้ายบรรทัดและจัดต้นฉบับ

**Option+Up/Down / Alt+Up/Down** ย้ายบรรทัด **Command+Shift+D / Ctrl+Shift+D** ทำสำเนา และ **Command+' / Ctrl+'** สลับ HTML comment ส่วนป๊อปอัปตารางใช้ **Command+/ / Ctrl+/**

ใช้ **Option+Command+F / Alt+Ctrl+F** จัดรูปแบบทั้งเอกสาร หากมีช่วงเลือก โปรแกรมจะขยายให้เต็มบรรทัดและจัดเฉพาะส่วนนั้น คำสั่งนี้จัดระเบียบต้นฉบับ เช่น ช่องไฟและแนวตาราง และเลิกทำทั้งรายการได้ด้วย Undo ครั้งเดียว

สำหรับโครงสร้างที่อาศัยบริบทส่วนอื่น เช่น เชิงอรรถหรือรายการต่อเนื่อง ควรจัดทั้งเอกสารเพื่อให้เห็นบริบทครบ เครื่องมือจัดรูปแบบโหลดเมื่อใช้ครั้งแรก หากเอกสารเปลี่ยนระหว่างโหลด ผลเก่าจะถูกทิ้ง ให้ลองสั่งอีกครั้งหลังหยุดแก้ไข

## แยกการแสดงผลออกจากเนื้อหา

Soft wrap เปลี่ยนเฉพาะวิธีแสดงบรรทัดยาว ไม่ได้ใส่ newline ลงไฟล์ ส่วนการกด Return และการเยื้องเปลี่ยนข้อความจริง หากเปิดในโปรแกรมอื่นแล้วดูต่างกัน ให้ตรวจต้นฉบับก่อนสรุปว่า wrapping แก้ไฟล์

ปรับการเยื้อง ความสูงบรรทัด การเติมวงเล็บ Focus และ Typewriter ได้ใน [Preferences](preferences.html) การตั้งค่าแสดงผลแยกจากประวัติ Undo ของเนื้อหา
