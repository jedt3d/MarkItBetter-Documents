# ไฟล์และโฟลเดอร์งาน

ใช้ **Favorites** สำหรับตำแหน่งที่เปิดบ่อย และ **Files** สำหรับเรียกดูโฟลเดอร์ที่กำลังทำงาน ทั้งสองแผงทำงานกับไฟล์จริง การเปลี่ยนชื่อหรือย้ายไฟล์จึงเปลี่ยนตำแหน่งบนดิสก์ด้วย

## จัดโฟลเดอร์โครงการ

1. รวมเอกสารโครงการไว้ในโฟลเดอร์ เช่น `project-notes`
2. เพิ่มโฟลเดอร์ผ่าน Favorites หรือเปิดเอกสารที่อยู่ภายใน
3. แสดง Favorites ด้วย **Command+1 / Ctrl+1** และ Files ด้วย **Command+2 / Ctrl+2**
4. เลือกโฟลเดอร์ที่จะเรียกดู แล้วใช้ Files เปิดเอกสารหรือเข้าโฟลเดอร์ย่อย

ปรับขนาดแผงหรือซ่อนเมื่ออยากได้พื้นที่สำหรับตารางกว้างและแผนภาพ ความกว้างพรีวิวคำนวณจากพื้นที่ที่เหลือด้วย ดู [รูปลักษณ์](appearance.html#content-width) เพื่อเข้าใจเหตุผลที่คอลัมน์อ่านเปลี่ยนเมื่อเปิดทั้งสองแผง

## เปิดไฟล์ด้วยชื่อ

กด **Command+P / Ctrl+P** เพื่อเปิด Quick Open โปรแกรมจะค้นหาในโฟลเดอร์ Favorites ที่เลือก หรือโฟลเดอร์ของเอกสารปัจจุบัน พิมพ์ชื่อหรือส่วนหนึ่งของพาธ เลือกด้วยลูกศร แล้วกด Enter ตัวกรองอย่าง `notes/` ช่วยจำกัดผลตามโฟลเดอร์ได้

Quick Open ใช้ค้นหาไฟล์จากชื่อและพาธ ไม่ได้ค้นหาทุกประโยคในทุกเอกสาร หากต้องการหาข้อความในไฟล์ปัจจุบัน ให้ใช้ [Find](navigation.html#find-in-preview-and-edit)

## จัดการไฟล์

สร้างไฟล์หรือโฟลเดอร์ผ่านปุ่มที่เกี่ยวข้องหรือ command palette เมนูคลิกขวาของแถวใน Files มี **Rename…** และ **Move to Trash** ตรวจแถวที่เลือกก่อนสั่งงาน หากเปลี่ยนชื่อหรือย้ายไฟล์ที่เปิดอยู่ผ่าน MIB โปรแกรมจะปรับพาธให้ หากไฟล์ถูกลบ ข้อความอาจยังอยู่ในตัวแก้ไข แต่ต้อง **Save As…** เพื่อให้มีปลายทางที่ใช้ได้อีกครั้ง

รุ่นเผยแพร่ลากแถวไปวางบนโฟลเดอร์เพื่อย้ายเข้าไปได้ ส่วนการลากไป Favorites คือการเพิ่มรายการโปรด เลือกการใช้งานให้ตรงจุดประสงค์: บุ๊กมาร์กช่วยเปิดเร็วขึ้น ขณะที่การย้ายเปลี่ยนตำแหน่งจริง

ใช้ **Sort** จัดลำดับรายการ การแสดงวันที่และข้อความตัวอย่างเป็นตัวเลือกด้านการแสดงผล การเรียงตามวันที่จึงไม่ได้แปลว่ากำลังแสดงคอลัมน์วันที่ด้วย ตัวกรองเปลี่ยนเฉพาะรายการที่มองเห็น ไม่เปลี่ยนชื่อหรือเนื้อหาไฟล์

## เก็บไฟล์อ้างอิงไว้ด้วยกัน

```text
project-notes/
  overview.md
  decisions.md
  images/
    architecture.svg
```

ใน `overview.md` ใช้ `[บันทึกการตัดสินใจ](./decisions.md)` และ `![แผนภาพสถาปัตยกรรม](./images/architecture.svg)` ได้ ทั้งคู่ต้องอาศัยโฟลเดอร์ของเอกสารที่บันทึกแล้ว สำหรับกฎเข้าถึงรูปในรุ่นเผยแพร่ ให้เก็บรูปภายในโฟลเดอร์นั้นหรือโฟลเดอร์ย่อย

หลังจัดโครงสร้างโครงการใหม่ ควรตรวจลิงก์สัมพัทธ์อีกครั้ง เพราะฐานพาธเปลี่ยนตามเอกสาร สำรองไฟล์หรือบันทึกในระบบ version control ก่อนเปลี่ยนโครงสร้างที่กู้คืนได้ยาก
