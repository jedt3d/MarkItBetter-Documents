# จัดการตารางใน Markdown

MIB แก้ตาราง GFM แบบ pipe เป็นข้อความ คำสั่งเชิงโครงสร้างช่วยเพิ่มหรือลบแถวและคอลัมน์โดยไม่ต้องย้ายเส้นแบ่งเองทุกจุด แล้วตรวจผลใน PREVIEW ได้

## สร้างตารางเริ่มต้น

เลือก **Table** จาก slash menu แล้วกรอกช่อง หรือวางต้นฉบับนี้

```markdown
| รายการ | ผู้รับผิดชอบ | สถานะ |
| :--- | :--- | ---: |
| คู่มือผู้ใช้ | Docs | ร่าง |
| บันทึก API | Platform | พร้อม |
```

เครื่องหมาย colon ในแถวคั่นกำหนดการจัดแนว: `:---` ชิดซ้าย `:---:` กึ่งกลาง และ `---:` ชิดขวา ในพรีวิว ตารางที่กว้างกว่าคอลัมน์อ่านสามารถเลื่อนในพื้นที่ของตารางได้

## เปิดป๊อปอัปตาราง

วางเคอร์เซอร์ในตารางแล้วกด **Command+/ / Ctrl+/** จะมีคำสั่งดังนี้

- **Insert Row Above** และ **Insert Row Below** เพิ่มแถวบนหรือล่าง
- **Insert Column Left** และ **Insert Column Right** เพิ่มคอลัมน์ซ้ายหรือขวา
- **Delete Row** และ **Delete Column** ลบแถวหรือคอลัมน์

ใช้ลูกศรกับ Enter คลิกคำสั่ง หรือ Esc เพื่อปิด หากอยู่บนบรรทัดว่างติดกับตารางด้านบนหรือล่าง การเปิดป๊อปอัปอาจย้ายเคอร์เซอร์เข้าสู่เซลล์ที่ใกล้ที่สุด ตรวจตำแหน่งก่อนสั่งแก้โครงสร้าง

Delete Row จะไม่ลบหัวตารางหรือแถวคั่น แต่การลบคอลัมน์สุดท้ายจะลบทั้งตาราง คำสั่งโครงสร้างแต่ละรายการเลิกทำได้หนึ่งครั้ง และจัดแนวตารางที่แก้โดยคง colon ระบุการจัดแนวไว้

## เพิ่มแถวด้วย Tab

เมื่ออยู่ **เซลล์สุดท้ายของแถวเนื้อหาสุดท้าย** ให้กด Tab เพื่อเพิ่มแถวใหม่และเลือกช่องแรก กรอกแล้วเลื่อนผ่านแต่ละช่อง เมื่อถึงท้ายแถวใหม่ก็เพิ่มต่อได้

พฤติกรรมพิเศษนี้ไม่ได้ทำให้ทุกเซลล์เดิมมีการนำทางแบบสเปรดชีต ช่อง snippet ที่ยังใช้งานมี Tab/Shift+Tab ของตัวเอง ส่วนตำแหน่งอื่น Tab อาจเยื้องข้อความ หากไม่มีลำดับช่องกรอก ให้ย้ายเคอร์เซอร์เองหรือใช้ป๊อปอัป

แถวที่เพิ่มอาจยังดูไม่เรียงตรงในต้นฉบับ ใช้ **Format Document** จัดแนวอีกครั้ง การจัดทั้งเอกสารเป็นคนละคำสั่งกับการจัดตารางทันทีจากป๊อปอัป

## รักษาข้อมูลระหว่างแก้ไข

ใช้ inline code กับตัวระบุ และ escape เครื่องหมาย pipe ที่เป็นข้อความด้วย `\|` ตามความจำเป็น ตรวจพรีวิวหลังแก้ลิงก์หรือโค้ดที่มีเครื่องหมายพิเศษ ฟอนต์โมโนช่วยจัด pipe แต่ความกว้างตัวอักษรหลายภาษาอาจยังต่างกัน ให้ยึดความหมายที่แสดงจริงมากกว่าจำนวนช่องว่าง

ตารางตัวเลขควรใช้รูปแบบจำนวนสม่ำเสมอและจัดคอลัมน์ชิดขวา MIB เป็นตัวแก้ไข Markdown ไม่คำนวณสูตรหรือปรับข้อมูลการเงินอัตโนมัติ คำนวณในเครื่องมือที่รับผิดชอบข้อมูลนั้น แล้วใส่ค่าที่ตั้งใจอธิบายลงเอกสาร
