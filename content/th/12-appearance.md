# รูปลักษณ์และความสบายในการอ่าน

หน้าต่างแอป ธีมเอกสาร ฟอนต์พรีวิว และสีโค้ดเกี่ยวข้องกันแต่แยกหน้าที่ ควรปรับชั้นที่ทำให้เกิดปัญหา แทนการเปลี่ยนทุกอย่างพร้อมกัน

## Appearance ของหน้าต่างและธีมเอกสาร

ปุ่ม appearance บน toolbar วนระหว่าง **system**, **light** และ **dark** แถบเครื่องมือ แผง และหน้าต่างย่อยใช้ค่านี้ ส่วนพื้นที่เอกสารใช้ระบบธีม

ใน Preferences ตัวเลือก **Match system appearance** ให้เอกสารตาม appearance ที่สรุปใช้อยู่ การเลือก **Theme** โดยตรงปิดการตามระบบ หากเปลี่ยน toolbar แล้วเอกสารไม่เปลี่ยน ให้ตรวจว่าเลือกธีมคงที่ไว้หรือไม่

## ความกว้างเนื้อหา {#content-width}

กฎอัตโนมัติพิจารณาขนาดหน้าต่างและแผงที่เปิด

| สถานการณ์ | ความกว้างพรีวิวอัตโนมัติ |
| --- | --- |
| หน้าต่างธรรมดาหรือแคบ | Wide หรือ 90% ของแผง |
| หน้าต่างกว้าง/fullscreen เปิดแผงด้านข้างศูนย์หรือหนึ่งแผง | Centered หรือ 60% |
| หน้าต่างกว้าง/fullscreen เปิดทั้งสองแผง | Wide หรือ 90% |

เกณฑ์หน้าต่างกว้างคือ 75% ของความกว้างจอ การเลือก **Content width** เองคงอยู่จนเปิดไฟล์อื่น เหมาะกับตารางกว้างหรือบันทึกเฉพาะชิ้น แต่ไม่ได้แทนกฎอัตโนมัติถาวร

Mermaid viewer ที่จะตามมาถูกจำกัดด้วยคอลัมน์ที่มีจริงนี้ ความกว้างเอกสารกับรูปทรงแผนภาพทำงานร่วมกัน การเพิ่มอย่างหนึ่งไม่จำเป็นต้องยืดแผนภาพเล็กให้ใหญ่ขึ้น

## เลือกฟอนต์จากข้อความที่อ่านจริง

ตัวเลือก Preview มี IBM Plex และ Noto พร้อม Body style สำหรับ Noto ส่วน Editor เลือกฟอนต์โมโนที่ติดตั้งแยกกัน ลองทุกระบบอักษรในเอกสาร ไม่ใช้เพียงหัวข้อภาษาอังกฤษตัดสิน

เว็บคู่มือนี้ใช้ **IBM Plex Sans** สำหรับละติน **IBM Plex Sans Thai Looped** สำหรับเนื้อหาไทย **IBM Plex Sans Thai** สำหรับหัวข้อไทยขนาดใหญ่ **IBM Plex Sans JP** สำหรับญี่ปุ่น และ **IBM Plex Mono** พร้อม fallback ที่เหมาะสมสำหรับโค้ด ตัวหนาในเนื้อหาไทยยังคงเป็นแบบมีหัว ความสูงบรรทัดหัวข้ออย่างน้อย 1.2 เท่าของฟอนต์ และ 1.4 สำหรับไทยหรือญี่ปุ่น

นี่เป็นการเลือก typography ของคู่มือ ไม่ได้หมายความว่าทุกเครื่องติดตั้งฟอนต์ตรงกัน หรือ MIB เพิ่มแผงกำหนดฟอนต์รายภาษา ในแอปให้ใช้ preset ที่มีจริงแล้วตรวจย่อหน้า วรรณยุกต์ โค้ด และตาราง

## CSS พรีวิวที่กำหนดเอง {#custom-preview-css}

เริ่มจาก **Preferences → Color → Download Starter CSS Template** ซึ่งระบุ selector ที่พรีวิวรองรับ บันทึกเป็น CSS แล้วใช้ **Load CSS…** ในแท็บเดียวกัน การทับเพียงไม่กี่กฎเข้าใจและย้อนกลับง่ายกว่าสไตล์ทั้งเว็บไซต์

```css
.preview {
  line-height: 1.8;
}

.preview h1,
.preview h2,
.preview h3 {
  line-height: 1.4;
}

.preview p {
  margin-block: 0.8em;
}
```

ใช้ line height แบบไม่มีหน่วยเพื่อให้ปรับตามฟอนต์ รักษาพฤติกรรมเลื่อนของตารางและโค้ด เลือกตัวแปรสีของ template เมื่อต้องการให้สไตล์ยังใช้กับทั้งโหมดสว่างและมืด

CSS ที่โหลดชนะกฎธีม หาก picker ดูไม่มีผลหรือหัวข้อเบียด ให้ **Clear CSS** ตรวจสภาพเริ่มต้น แล้วคืนเฉพาะกฎที่จำเป็น Export `.mib_style` สำหรับสีธีมและเก็บ CSS แยกกัน เพราะเป็นการปรับแต่งคนละชนิด
