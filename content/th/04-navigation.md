# นำทางด้วยคีย์บอร์ด

MIB มี Quick Open สำหรับไฟล์ Outline สำหรับหัวข้อ และ command palette สำหรับคำสั่ง คีย์ลัดคล้ายกัน แต่แต่ละอย่างช่วยคนละงาน

## เลือกเครื่องมือให้ตรงงาน

| ต้องการ | Mac | Windows/Linux |
| --- | --- | --- |
| เปิดหน้าต่างเลือกไฟล์ | Command+O | Ctrl+O |
| หาไฟล์จากชื่อหรือพาธ | Command+P | Ctrl+P |
| ไปยังหัวข้อในเอกสาร | Command+Shift+O | Ctrl+Shift+O |
| เรียกคำสั่งของโปรแกรม | Command+Shift+P | Ctrl+Shift+P |

พิมพ์เพื่อกรอง ใช้ Up/Down เลือก Enter เพื่อยืนยัน และ Esc เพื่อปิด command palette รวมคำสั่งไฟล์ จัดรูปแบบ สลับโหมด แสดงแผง และเปิด Preferences รายการบางอย่างขึ้นอยู่กับโหมดและการมีพาธของเอกสาร

Outline เหมาะกับบันทึกทางเทคนิคยาว ๆ ที่มีหลายหัวข้อ ค้นหาชื่อหัวข้อแทนการเลื่อนทุกย่อหน้า ส่วนการนำทางโฟลเดอร์ยังเป็นหน้าที่ของ Files

## ค้นหาใน PREVIEW และ EDIT {#find-in-preview-and-edit}

**Command+F / Ctrl+F** ค้นหาในสิ่งที่โหมดปัจจุบันแสดง

ใน **PREVIEW** จะค้นหาข้อความที่จัดรูปแบบแล้วโดยไม่เปลี่ยนไป EDIT กด Enter เพื่อไปผลถัดไป Shift+Enter เพื่อย้อนกลับ และ Esc เพื่อปิด เหมาะเมื่อจำคำที่ผู้อ่านเห็นได้ แต่จำเครื่องหมายในต้นฉบับไม่ได้

ใน **EDIT** การค้นหาและแทนที่ทำกับต้นฉบับ มีตัวเลือกแยกตัวพิมพ์เล็กใหญ่ regular expression การแทนที่ทีละจุด และ Replace All เมื่ออยู่ในช่องค้นหา Enter ไปผลถัดไป ส่วน **Shift+Enter แทรกขึ้นบรรทัดใหม่ในคำค้น** สำหรับการค้นหาหลายบรรทัด จึงไม่ใช่คีย์ย้อนผลแบบใน PREVIEW ใช้ปุ่มก่อนหน้าและถัดไปตามบริบท

เมื่อเปิดค้นหาใหม่ ข้อความที่เลือกไว้หนึ่งบรรทัดอาจถูกใช้เป็นคำค้น หาก regular expression ไม่ถูกต้อง แผงจะแสดงสถานะผิดพลาด ก่อน Replace All ให้ตรวจคำค้น การแยกตัวพิมพ์ โหมด regex ข้อความแทน และจำนวนผลลัพธ์ โดยเฉพาะเมื่อเอกสารมีตัวระบุคล้ายกันหลายแห่ง

## ตามลิงก์

ลิงก์อย่าง `[การตั้งค่า](#configuration)` กระโดดไปยังหัวข้อในพรีวิว โดยใช้ slug แนวเดียวกับ GitHub: ตัดเครื่องหมายวรรคตอนและเติมเลขท้ายเมื่อชื่อซ้ำ หากต้องอ้างอิงหัวข้อสำคัญ ควรตั้งชื่อให้แตกต่างกัน

ลิงก์ Markdown แบบสัมพัทธ์จะเปิดเอกสารในโปรแกรม จึงต้องบันทึกไฟล์ปัจจุบันก่อนเพื่อให้มีฐานพาธ ลิงก์ HTTP/HTTPS จะเปิดในเบราว์เซอร์ของระบบ

## โฟกัสและ IME

เมื่อโฟกัสอยู่ในหน้าต่างคำสั่ง ลูกศรและ Enter จะทำงานกับหน้าต่างนั้น ปิดก่อนหากต้องการขยับเคอร์เซอร์ในเอกสาร ขณะใช้วิธีป้อนภาษาไทยหรือญี่ปุ่น ให้จบการประกอบข้อความก่อนใช้ปุ่มสลับโหมด สำหรับ command palette ให้ใช้คีย์ลัดด้านบน ไม่ใช้การกด Shift สองครั้งตามความเคยชินจากโปรแกรมอื่น
