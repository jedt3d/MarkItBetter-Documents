# 表示と読みやすさ

ウィンドウ、文書テーマ、プレビュー書体、コード配色は関連しますが別の設定です。すべてを同時に変えず、問題のある層を調整します。

## ウィンドウ表示と文書テーマ

toolbar の appearance 操作は **system**、**light**、**dark** を切り替えます。ツールバー、パネル、ダイアログはこの表示を使い、文書の領域はテーマシステムに従います。

Preferences の **Match system appearance** は文書を解決された表示に追従させます。明示的な **Theme** を選ぶと追従はオフです。toolbar を切り替えても文書が変わらなければ、固定テーマを選んでいないか確認します。

## 内容幅 {#content-width}

自動規則はウィンドウと開いているパネルを使います。

| 状態 | 自動プレビュー幅 |
| --- | --- |
| 通常・狭いウィンドウ | Wide、パネルの 90% |
| 広い・fullscreen、サイドパネルが 0 または 1 | Centered、60% |
| 広い・fullscreen、両パネルを表示 | Wide、90% |

広いウィンドウの基準は画面幅の 75% です。手動の **Content width** は別ファイルを開くまで有効です。幅広の表や特定のノートには便利ですが、自動規則を永久に置き換える設定ではありません。

今後の Mermaid ビューアーも、この実際の列幅を上限にします。文書の幅と図の寸法は連動するため、列を広げても小さい図を必ず引き伸ばすわけではありません。

## 実際に読む文字で書体を選ぶ

Preview は IBM Plex と Noto を選べ、Noto には本文スタイルがあります。Editor のインストール済み等幅書体とは独立しています。英語見出しだけで判断せず、文書で使う文字体系を試します。

このガイドは欧文に **IBM Plex Sans**、タイ語本文に **IBM Plex Sans Thai Looped**、大きなタイ語見出しに **IBM Plex Sans Thai**、日本語に **IBM Plex Sans JP**、コードに **IBM Plex Mono** と適切な補完書体を使います。本文の太字もループ付きタイ語を保ちます。見出し行間は最低 1.2 倍、日本語・タイ語は 1.4 倍です。

これはガイドの文字組み方針であり、読者の全端末に同じ書体が入っているという意味や、MIB に言語別の新しい設定画面があるという意味ではありません。アプリでは利用可能な preset を選び、段落、結合記号、コード、表を確認します。

## カスタム Preview CSS {#custom-preview-css}

**Preferences → Color → Download Starter CSS Template** から始めます。対応する selector が載っています。編集を CSS として保存し、同じタブの **Load CSS…** で読み込みます。小さな上書きの方が、Web サイト全体の CSS より理解と復元が容易です。

```css
.preview {
  line-height: 1.8;
}

.preview h1,
.preview h2,
.preview h3 {
  line-height: 1.4;
}

.preview p {
  margin-block: 0.8em;
}
```

行間は単位なしにして書体サイズに追従させます。表とコードのはみ出し処理を保ち、明暗両テーマで使いたければ template の色変数を優先します。

読み込んだ CSS はテーマより優先されます。色が効かない、見出しが詰まるときは **Clear CSS** で基準を確認し、必要なルールだけ戻します。テーマ色の `.mib_style` と CSS は別の調整材料として保存してください。
