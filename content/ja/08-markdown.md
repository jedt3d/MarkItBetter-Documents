# 対応する Markdown 記法

公開版が扱うのは CommonMark、GFM、および明示された小さな拡張です。既存の Markdown の知識を使えますが、他のエディターの拡張がそのまま MIB にもあるとは限りません。

## 日常的なソース

```markdown
## 設定

**太字**、*斜体*、`inline code`、~~古い記述~~を使います。

> 判断の近くに理由を残します。

1. ノートを開く。
2. 変更する。

- [ ] サンプルを確認する
- [x] 文書を保存する
```

見出し、リスト、引用、リンク、画像、フェンスやインデントによるコード、水平線は通常の Markdown です。GFM はパイプ表、取り消し線、タスクリスト、オートリンクを追加します。[タスク](preview.html#interactive-task-lists)は PREVIEW からも切り替えられます。

## リンク・画像・アンカー

```markdown
[外部資料](https://example.com)
[別のノート](./decisions.md)
[Configuration 節](#configuration)
![画像の説明](./images/architecture.svg)
```

相対参照を使う前に現在の文書を保存してください。ローカル画像は文書と同じディレクトリか、その配下に置きます。公開版の画像アクセスには範囲があり、上位へ抜けるパスは失敗する場合があります。最初の Save As 後に解決しなければ文書を開き直します。

見出しのスラッグはタイ語や日本語の文字を保ち、適切な文字を小文字にし、記号を除き、空白をハイフンにします。固有の見出し名にすると手書きのリンクが安定します。HTTP/HTTPS はブラウザー、相対 Markdown リンクはアプリ内で開きます。

## MIB の小さな拡張

| ソース | 意味 |
| --- | --- |
| `H~2~O` | 下付き |
| `x^2^` | 上付き |
| `[[Ctrl + S]]` | PREVIEW のキーチップ |
| `:smile:` | 対応する絵文字ショートコード |
| `[^note]` と `[^note]: text` | 脚注参照と定義 |

キーチップは文字列をそのまま表示し、内部に Markdown を入れ子にしません。閉じていない、または空のチップは通常の文字です。脚注には別の場所の定義を使い、`^[text]` のインライン形式は使いません。PREVIEW が整形する拡張でも、エディター上は通常のソース表示の場合があります。

## コードと HTML

コードフェンスの言語名が構文強調を選びます。`js`、`ts`、`py`、`sh` などの一般的な別名も使えます。未対応の言語は読みやすいプレーンコードのままです。[Preferences → Code](preferences.html#code) で配色を選べます。

`<details>` と `<summary>` は折りたたみに使えます。HTML は無害化され、script やイベントハンドラーが除かれ、能動的な埋込みも制限されます。任意の JavaScript、iframe、Web ウィジェットが動くことを前提にしないでください。

インライン SVG は公開版の安全性制約内で使えます。スクリプト付き SVG、`foreignObject`、外部参照、一部の `<use>` ベースの描画は残りません。構造を展開した受動的なベクター出力の方が共有しやすくなります。

## 共有前に互換性を確かめる

Mermaid は **今後の機能**であり、v0.49.0 はフェンスをコードとして表示します。数式、wiki-link、callout/admonition は、この公開版の記法には含まれません。このガイドの Web 表示だけで、インストール済み MIB も同じ拡張を扱えると判断しないでください。

共有ノートは通常の Markdown から始め、PREVIEW を確認し、チームの別のツールでも代表的なファイルを開きます。新しいレンダラーや拡張を試すときは元のソースを保管します。
