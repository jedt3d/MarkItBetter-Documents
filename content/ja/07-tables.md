# Markdown のまま表を編集する

MIB は GFM のパイプ表をテキストとして扱います。構造操作で行・列を変更すれば、すべての区切りを手で動かす必要がなく、PREVIEW で読み手の見え方を確認できます。

## 表を作る

スラッシュメニューの **Table** を選んでフィールドを埋めるか、次を貼り付けます。

```markdown
| 項目 | 担当 | 状態 |
| :--- | :--- | ---: |
| ユーザーガイド | Docs | 下書き |
| API ノート | Platform | 準備完了 |
```

区切り行のコロンが配置を決めます。`:---` は左、`:---:` は中央、`---:` は右寄せです。プレビューの読み幅より広い表は、その領域内で横スクロールできます。

## 表のポップアップを開く

表にカーソルを置いて **Command+/ / Ctrl+/** を押します。

- **Insert Row Above / Below**：上または下に行を追加。
- **Insert Column Left / Right**：左右に列を追加。
- **Delete Row / Column**：行または列を削除。

矢印と Enter、またはクリックで選び、Esc で閉じます。表の直前・直後の空行で開くと、近いセルへカーソルが移ることがあります。構造を変える前に対象セルを確認してください。

見出し行と区切り行は Delete Row で消せません。最後の一列を削除すると表全体が消えます。構造変更は一回の Undo で戻せ、配置のコロンを保ったまま編集した表をそろえます。

## Tab で行を追加する

**最後のデータ行の最後のセル**で Tab を押すと、新しい行を追加し、その先頭フィールドを選択します。入力して各フィールドを進み、末尾からさらに行を追加できます。

この動作ですべての既存セルが表計算式の移動になるわけではありません。有効なスニペットには専用の Tab/Shift+Tab があり、その他の位置では Tab がインデントする場合があります。フィールドが有効でなければ、カーソルを移すかポップアップを使います。

追加直後の行はソース上でそろっていない場合があります。**Format Document** で再整形してください。文書全体の整形と、ポップアップによる表だけの即時整形は別の処理です。

## データを守って編集する

識別子にはインラインコードを使い、文字として必要なパイプは `\|` とエスケープします。記号を含むコードやリンクを変更したら PREVIEW を確認します。等幅フォントでも複数の文字体系では幅が異なるため、ソースの空白数より表示された意味を重視してください。

数値表は表記を統一して数値列を右寄せにします。MIB は Markdown エディターであり、表の数式計算や財務数値の更新は行いません。計算を管理するツールで値を確定し、文書には説明したい値を記録します。
