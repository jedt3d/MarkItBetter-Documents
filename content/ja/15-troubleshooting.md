# 困ったときと機能の提供状況

まずバージョン、モード、小さな再現例を確認します。「v0.49.0 の EDIT で Link スニペット挿入後」の方が、「キーボードが止まった」より原因を調べやすくなります。

## キーが予想と違う動作をする

メニューや検索を閉じ、文書へフォーカスを戻します。Esc はスニペットを終えてから PREVIEW へ戻る場合があります。フィールド終了後の Tab はインデントすることがあります。PREVIEW の `i` は可能なら選択を使い、なければ末尾へ移るため、正確な単語の変更にはダブルクリックを使います。

[操作対象別のキー](shortcuts.html#focus-sensitive-keys)、OS の修飾キー処理、IME を確認してください。Replace All の繰り返しや大きな構造変更の前に、例を保存しておきます。

## ファイルを開けない・保存できない

テキストファイルか、保存先が書込み可能かを確認します。画像、PDF、アーカイブ、動画を Markdown として開かないでください。無題の内容には Save As の保存先が必要です。MIB の外で移動・削除した場合は実際のパスを確認します。

保存エラー時はエディターを開いたままにします。大切な文字を安全な場所へコピーし、エラーを残し、保存済みのコピーを確認するまで buffer を破棄しません。成功後にコピーを開き直し、ディスクの内容を確認することもできます。

## ローカル画像やリンクが見つからない

文書を実際のプロジェクトへ保存し、素材を同じディレクトリかその配下に置き、名前の大小文字と Markdown を確認します。相対パスは文書の場所が基準です。初回 Save As 後に解決しなければ文書を開き直してください。

公開版の画像アクセス範囲は、文書ディレクトリの外を拒否する場合があります。報告には小さな `.md` と無害な素材を一つのフォルダーに入れ、単純な相対パスを使います。リンクの問題を示すために私的なプロジェクト全体を送る必要はありません。

## 文字が詰まる・設定が反映されない

[Preferences](preferences.html) のモード制限を確認します。Editor の行間と Preview CSS は別です。書体変更後は実際の日本語・タイ語を確認し、文字より小さい固定行高を避けます。

読み込んだ CSS がテーマを上書きする場合は **Clear CSS** で基準を確認してから必要なルールを戻します。別ファイルで幅が戻るのはセッション上書きの仕様です。固定テーマが system/light/dark に追従しなければ **Match system appearance** を確認してください。

## コードに色が付かない

フェンスの言語名を確認します。未知の grammar は意図的にプレーン表示し、対応言語も本文の後から色が付く場合があります。**Preferences → Code** で配色を選びます。HTML の script や能動的な widget は、周囲の Markdown が正しくても制限されます。

## 公開済みと今後の機能

| 状態 | 期待できるもの |
| --- | --- |
| 公開版 v0.49.0 | PREVIEW/EDIT、ローカルテキスト、Favorites/Files、Quick Open/Outline/palette、slash fields、表編集、対応記法、Preferences とスタイル |
| レビュー済み Mermaid 開発 | 中央フレーム、構文強調 Source、アプリ領域の最大化・復元、図の種類と多言語文字組み。v0.49.0 には未搭載 |
| 次のビューアー改訂 | Fit All、zoom/pan、ホバーで表示する操作を調整中。統合・検証も未完了 |
| 公開版の範囲外 | 独自 Smart Snippets、任意の Mermaid 拡張、wiki-link/callout/math、その他未発表の機能 |

v0.49.0 で Mermaid がコードとして見えるのは想定どおりです。[Mermaid の章](mermaid.html)で準備と互換性を学び、実際の release notes を見てから利用可能と判断します。

## 調査できる報告を用意する

アプリ版、OS とアーキテクチャー、モード、手順、期待結果、実際の結果、見えるエラーを記録します。問題が残る最小の文書へ減らしてください。文字組みなら実際の文字と preset、図なら正確なフェンスと設定を残します。

公式サポート経路を使い、秘密情報、個人のパス、token、私的な文書内容を除いてください。修正版が公開されたら公式経路で更新し、同じ最小例を再実行します。
