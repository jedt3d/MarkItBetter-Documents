# インストールと最初の設定

MarkItBetter（MIB）は、整形された文書を読み、必要なときにソースを編集し、また読む、という流れを中心にしたデスクトップ用 Markdown エディターです。ファイルは通常のテキストのままです。このガイドは Markdown に慣れた開発者やパワーユーザーを対象に、MIB 固有の操作を説明します。

公開済み機能の説明は **v0.49.0** を対象とします。[Mermaid の章](mermaid.html)では開発中の機能を分けて扱います。ガイドに登場する機能が、手元の古いバージョンでも使えるとは限りません。

## インストーラーを選ぶ

公式のダウンロード元または購入時の配布先から取得し、OS とプロセッサーの両方を確認してください。

| コンピューター | v0.49.0 のパッケージ |
| --- | --- |
| Apple Silicon Mac | `MarkItBetter_aarch64.dmg` |
| Intel Mac | `MarkItBetter_x64.dmg` |
| x64 Windows | `MarkItBetter_0.49.0_x64-setup.exe` |
| ARM64 Windows | `MarkItBetter_0.49.0_arm64-setup.exe` |
| amd64 Debian/Ubuntu | `MarkItBetter_0.49.0_amd64.deb` |
| arm64 Debian/Ubuntu | `MarkItBetter_0.49.0_arm64.deb` |

macOS ではディスクイメージを開いて Applications にインストールします。Windows では対応するインストーラーを実行します。Debian/Ubuntu ではパッケージマネージャーを使います。amd64 のファイルを保存したディレクトリで実行する例です。

```sh
sudo apt install ./MarkItBetter_0.49.0_amd64.deb
```

実際に取得したファイル名に合わせてください。OS がインストールや検証の問題を報告した場合は、入手元とアーキテクチャーを確認し、問い合わせ用にエラー全文を残します。

## 最初の文書を開く

1. MIB を起動します。通常はウェルカム文書が PREVIEW で開きます。OS からファイルを指定して起動した場合は、そのファイルが開きます。
2. **Open File…**、フォルダーのボタン、または **Command+O / Ctrl+O** で Markdown を開きます。
3. PREVIEW で読み、直したい単語をダブルクリックします。キーボード操作は [MIB のワークフロー](workflow.html)を参照してください。
4. 新規文書はアプリの操作ボタンかコマンドパレットの **New File** から作ります。相対パスの画像や文書リンクを使う前に保存先を決めます。

MIB は Markdown のほか、一般的なコードやマークアップなどのテキストも開けます。PDF、アーカイブ、画像、動画は編集対象のテキスト文書ではありません。画像そのものを開く操作と、Markdown から画像を参照する操作は別です。

## キー表記と更新

Mac の修飾キーは **Command**、**Option** と表記します。Windows/Linux では多くが **Ctrl**、**Alt** に対応します。[ショートカット一覧](shortcuts.html)で両方の表記と操作対象を確認できます。**Preferences**、**Media & Code** などの UI 名は、アプリと照合できるよう英語のまま記載します。

挙動を比較する前に **About MarkItBetter** でインストール済みのバージョンを確認してください。製品オーナーが示す価格は **$13**、**アップグレードは生涯無料**です。このガイドで別のサブスクリプションや認証手順を定めるものではありません。文書をバックアップし、更新版は公式の配布経路から取得します。
