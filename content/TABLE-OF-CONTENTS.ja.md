# MarkItBetter — 目次案

Markdown を使い慣れた開発者とパワーユーザーへ。

デザインと章構成のレビュー用サンプル。公開版ガイドは v0.49.0、Mermaid は開発完了プレビューです。

## 1. インストールと最初の設定

- インストール、初回起動、プラットフォームごとの注意点
- $13 の価格と生涯無料アップグレードの方針

## 2. MIB のワークフロー

- プレビューを起点に、i で編集、Esc で読む
- 自動保存、未保存ファイル、プレビューからソースへの移動

## 3. ファイルと作業フォルダー

- 開く、保存、タブ、最近使ったファイル、お気に入り
- クイックオープンとローカル Markdown リンク

## 4. キーボードで移動する

- コマンドパレット、見出しアウトライン、クイックオープン
- プレビュー内検索とエディターの検索・置換

## 5. 正確に編集する

- 複数カーソル、矩形選択、行操作
- フォーカスモード、整形、元に戻す

## 6. スラッシュメニューと入力フィールド

- リンク、画像、コード、表、折りたたみブロックを挿入
- Tab と Shift+Tab で移動し、Esc で終了

## 7. Markdown のまま表を編集する

- カーソル位置から行・列を操作
- Tab で行を追加し、整形でソースをそろえる

## 8. 対応する Markdown 記法

- タスク、脚注、ハイライト、コード、折りたたみ
- 動作例と安全な HTML の制限
- 画像・リンクの挿入とローカル参照
- パス、代替テキスト、表示されない画像の確認

## 9. Mermaid で図を扱う (開発版プレビュー)

- Mermaid コードブロックを書いて図を表示
- タイトル、アクセシブル名、無題のフォールバック
- 図を見ながら、下に構文強調された Source を表示
- 最大化、復元、Esc、フォーカスと読んでいた位置
- ラベルとソースを検索してエディターへ戻る
- Mermaid11.17.2 の図の種類、別名、承認済み互換性制限
- タイ語、日本語、混在スクリプト、長いラベル
- 図ごとのエラー、描画範囲、復旧、トラブルシューティング
- フローチャート、シーケンス、構成図、プロジェクトノートの例

## 10. プレビューとソースをつなぐ

- 読み幅、パネル、タスクチェック、ソース位置への移動
- 読み取りと編集を、位置を保ったまま切り替える

## 11. 読みやすい環境に整える

- プレビュー書体、ライト・ダーク表示、エディター書体
- タイ語のループ付き本文、日本語、プレビューのスタイル設定

## 12. 実務で使うレシピ

- README、技術メモ、リリース用チェックリスト
- 利用状況を明示した、図付きアーキテクチャノート

## 13. キーボードショートカット

- モード切替、移動、編集、表、入力フィールド
- macOS キーと、文書化された Windows/Linux の対応

## 14. 困ったときと今後の機能

- 保存、書体、ローカル画像、描画の問題
- 公開済み機能と開発完了機能の区別、更新情報、サポート
