スラッシュメニューと入力フィールド

公開版ガイド: v0.49.0

このページ
  • 開く・絞り込む・挿入する
  • フィールドを埋める
  • コピーできる例
  • Tab の動作が変わるとき

スラッシュメニューは通常の Markdown を挿入します。Tab で埋めるフィールドを持つ項目もあり、リンク、コード、表などの記号を繰り返し入力する手間を減らせます。

開く・絞り込む・挿入する

  1. EDIT で、行頭または空白の後に / を入力します。
  2. ブロック名の一部を入力してカテゴリ横断で絞り込むか、タブ行で Left/Right を使います。
  3. Down でグリッドへ入り、矢印で選択、Enter で挿入します。マウスでも選べます。
  4. 起点の slash が選んだブロックに置き換わり、フォーカスがエディターに戻ります。

Esc は入力した / を残してメニューを閉じます。URL や識別子の途中に slash を入力する操作は、有効な起点からメニューを開く操作とは異なります。

タブは Essential、Basic、Lists、Media & Code、Advanced です。Essential はローカルの挿入頻度を反映し、履歴が少ない間は既定の項目を使います。v0.49.0 では、独自スニペットの登録や任意の固定順位を編集する仕組みではありません。

フィールドを埋める

Link は表示名、Tab、URL、Tab の順です。Shift+Tab で前のフィールドへ戻れます。最後の Tab はリンク後の一文字分の空白の後へ移り、そのまま文を書き続けられます。

Image は代替テキストからパスへ、Code block は言語から本文へ進みます。Table は二つの見出しと最初のデータ行のフィールドを巡ります。Esc はフィールド移動を終了し、ほかの操作がキーを使っていなければ、次の Esc で PREVIEW へ戻ります。

Tab の動作が変わるとき

フィールド移動は、フィールドが有効な間の操作です。入力を終えるか解除すると通常のソースになり、Tab は通常のインデントへ戻ります。表の最後のデータ行の最後のセルでは、別の表コマンドが行を追加できます。すべてのセルで表計算のように移動すると考える前に、表の章を確認してください。

見出し、引用、区切り線、リスト、HTML ブロック、コメントなどの単純な挿入もあります。独自の Smart Snippets、自由な変数展開、Essential の手動並び替えは公開済みスラッシュメニューの機能ではありません。
