キーボードで移動する

公開版ガイド: v0.49.0

このページ
  • 目的に合う画面を開く
  • PREVIEW と EDIT の検索
  • リンクをたどる
  • フォーカスと IME

Quick Open はファイル、Outline は見出し、コマンドパレットは操作を探します。似たショートカットでも役割は異なります。

目的に合う画面を開く

目的 Mac Windows/Linux
ファイル選択ダイアログ Command+O Ctrl+O
名前・パスでファイル検索 Command+P Ctrl+P
文書の見出しへ移動 Command+Shift+O Ctrl+Shift+O
アプリのコマンドを実行 Command+Shift+P Ctrl+Shift+P

検索型のオーバーレイでは、入力して絞り込み、Up/Down で移動、Enter で決定、Esc で閉じます。パレットにはファイル、整形、モード切替、パネル、Preferences などの操作があります。現在のモードや保存先の有無で項目が変わる場合があります。

長い技術文書では、スクロールを続けるより Outline で見出しを検索する方が便利です。フォルダーの移動には Files を使います。

PREVIEW と EDIT の検索

Command+F / Ctrl+F は、現在見ている表現を検索します。

PREVIEW では、EDIT へ切り替えずに表示中のテキストを検索します。Enter で次、Shift+Enter で前の一致へ進み、Esc で閉じます。Markdown 記号よりも読み手に見える語句を探したいときに使います。

EDIT ではソースを検索・置換します。大文字小文字、正規表現、一件置換、Replace All を利用できます。検索欄の Enter は次の一致へ進みますが、Shift+Enter は検索文字列に改行を挿入して複数行のリテラル検索を作ります。PREVIEW の「前の一致」とは異なるため、前後移動のボタンも使い分けてください。

検索を新たに開くとき、選択中の一行のテキストを検索語に使える場合があります。不正な正規表現はエラー表示になり、そのまま適用されません。Replace All の前に検索語、大小文字、regex、置換文字列、一致件数を確認してください。識別子が似ている技術文書では特に重要です。

リンクをたどる

[設定](#configuration) のようなリンクはプレビュー内の見出しへ移動します。見出しのスラッグは GitHub 方式で、記号を除き、重複には番号が付きます。重要な参照先には固有の見出し名を付けると確実です。

相対 Markdown リンクはアプリ内で文書を開きます。基準ディレクトリが必要なので、現在の文書を先に保存してください。HTTP/HTTPS リンクはシステムのブラウザーで開きます。

フォーカスと IME

オーバーレイにフォーカスがある間、矢印と Enter はその操作に使われます。エディターのカーソルを動かす前に閉じてください。日本語・タイ語の入力中は、変換や文字の確定を終えてからモードを切り替えます。別のエディターの癖で Double-Shift を使わず、パレットには上記のショートカットを使います。
