ファイルと作業フォルダー

公開版ガイド: v0.49.0

このページ
  • 作業フォルダーを用意する
  • 名前から開く
  • ファイルを整理する
  • 相対参照をまとめる

Favorites は繰り返し使う場所、Files は作業中のディレクトリを見るために使います。実際のファイルを操作するため、名前の変更や移動はディスク上の場所にも反映されます。

作業フォルダーを用意する

  1. project-notes など、プロジェクト専用のディレクトリを作ります。
  2. Favorites からフォルダーを追加するか、その中の文書を開きます。
  3. Command+1 / Ctrl+1 で Favorites、Command+2 / Ctrl+2 で Files を表示します。
  4. 対象のフォルダーを選び、Files から文書やサブフォルダーへ移動します。

パネルは幅を調整でき、広い表や図を見るときには閉じられます。プレビュー幅も残りの領域から計算されます。両パネルを開いたときに読み幅が変わる理由は表示設定で説明します。

名前から開く

Command+P / Ctrl+P で Quick Open を開きます。選択中の Favorites フォルダー、または現在の文書のディレクトリを検索します。ファイル名やパスの一部を入力し、矢印で選んで Enter を押します。notes/ のような入力で、フォルダー名からも絞り込めます。

Quick Open は名前とパスからファイルを探す機能です。全ファイルの本文検索ではありません。現在の文書内の文字列は Find で検索します。

ファイルを整理する

新規ファイル・フォルダーのボタンか、対応するパレット項目を使います。Files の行のコンテキストメニューには Rename… と Move to Trash があります。実行する前に対象行を確認してください。開いている文書を MIB 内で改名・移動すると、文書のパスも更新されます。削除した場合、テキストがエディターに残っていても、新たな保存先を Save As… で指定する必要があります。

公開版では、行をフォルダーへドラッグするとその中へ移動できます。Favorites にドラッグするとブックマークになります。素早く開きたいのか、保存場所を変更したいのかで使い分けます。

Sort で並び順を変えられます。日付表示や本文の抜粋は表示用の選択肢です。日付順で並べても、その日付を現在表示しているとは限りません。フィルターは見える一覧を変え、ファイル名や内容そのものは変更しません。

相対参照をまとめる

text
project-notes/
  overview.md
  decisions.md
  images/
    architecture.svg

overview.md では [判断記録](./decisions.md) や ![構成図](./images/architecture.svg) と書けます。どちらも保存済み文書のディレクトリが基準です。公開版のローカル画像規則に合わせ、画像は同じディレクトリか、その配下に置きます。

プロジェクトを整理した後は相対リンクを見直してください。ファイルを移動すると解決基準が変わります。戻せない変更を避けるため、大きな整理の前にバックアップやバージョン管理のコミットを残します。
