正確に編集する

公開版ガイド: v0.49.0

このページ
  • 書式ショートカット
  • 複数箇所を一度に変更する
  • 行の移動とソース整形
  • 表示とファイルの内容を区別する

EDIT には Markdown の記号、リンク、コードフェンスを含むソースが表示されます。正確な変更には選択とテキスト操作を使い、PREVIEW で結果を確認します。

書式ショートカット

選択して Command+B / Ctrl+B で太字、Command+I / Ctrl+I で斜体、Command+E / Ctrl+E でインラインコードにします。同じ書式で包まれている箇所への再実行は、その書式を外します。Command+K / Ctrl+K は選択をリンク名にして URL フィールドへ移ります。

Option+Command+1…6 / Alt+Ctrl+1…6 で見出しレベルを設定し、同じレベルを繰り返すと解除します。Command+Shift+X / Ctrl+Shift+X は取り消し線、Command+Enter / Ctrl+Enter は行を未完了タスク、完了タスク、未完了へ切り替えます。

複数箇所を一度に変更する

識別子を選択して Command+D / Ctrl+D を押すと次の一致を選択に追加します。Command+Shift+L / Ctrl+Shift+L は一致をすべて選択します。入力前に範囲を確認してください。有効な選択すべてが同時に変更されます。

Mac では Option-click でカーソルを追加し、Option-drag で矩形選択できます。対応する Alt 操作はショートカット一覧も参照してください。デスクトップ環境が Alt とマウスの組合せを先に受け取る場合があります。矩形選択は、等幅フォントと画面内に収まる行で扱いやすくなります。

ダブルクリックは単語、行頭空白のダブルクリックは行全体、トリプルクリックは Markdown ブロックを選択します。見出し上では、同じか上のレベルの見出しまでのセクションを選択します。大きく切り取る前に範囲を確認してください。

行の移動とソース整形

Option+Up/Down / Alt+Up/Down は行移動、Command+Shift+D / Ctrl+Shift+D は行の複製です。HTML コメントの切替は Command+' / Ctrl+'、表のポップアップは Command+/ / Ctrl+/ です。

Option+Command+F / Alt+Ctrl+F で文書を整形します。空でない選択がある場合は行全体へ広げ、その断片を整形します。空白や表の配置をソース上で整える操作で、一回の Undo で戻せます。

別の場所にある脚注定義や継続するリストなど、周囲の意味に依存する構造では文書全体を整形すると文脈を保てます。初回は整形エンジンを読み込みます。その間に文書を変更すると古い結果は破棄されるため、編集が落ち着いてから再実行してください。

表示とファイルの内容を区別する

Soft wrap は長い行の表示方法を変え、保存内容に改行を追加しません。Return やインデント操作は実際の文字を変更します。他のエディターで見え方が違う場合も、まずソースを確認してください。

Preferences でインデント、行の高さ、括弧補完、Focus、Typewriter を調整できます。表示設定とテキスト編集の Undo 履歴は別のものです。
