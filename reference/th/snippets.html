เมนู / และช่องกรอกใน snippet

คู่มือรุ่นเผยแพร่: v0.49.0

ในหน้านี้
  • เปิด กรอง และแทรก
  • กรอกแต่ละช่อง
  • ตัวอย่างที่คัดลอกได้
  • เมื่อ Tab ทำงานต่างออกไป

Slash menu แทรก Markdown ธรรมดา หลายรายการมีช่องให้กรอกด้วย Tab จึงเหมาะกับลิงก์ โค้ด ตาราง และโครงสร้างที่ต้องพิมพ์เครื่องหมายซ้ำ ๆ

เปิด กรอง และแทรก

  1. ใน EDIT พิมพ์ / ต้นบรรทัดหรือหลังช่องว่าง
  2. พิมพ์บางส่วนของชื่อบล็อกเพื่อค้นหาข้ามหมวด หรือใช้ Left/Right บนแถวแท็บ
  3. กด Down เข้าแผงบล็อก ใช้ลูกศรเลือก และ Enter เพื่อแทรก หรือใช้เมาส์
  4. บล็อกจะมาแทนเครื่องหมาย slash ที่เรียกเมนู แล้วโฟกัสกลับสู่ตัวแก้ไข

Esc ปิดเมนูและคง / ที่พิมพ์ไว้ การพิมพ์ slash กลาง URL หรือตัวระบุทั่วไปไม่ใช่ตำแหน่งเรียกเมนูแบบเดียวกัน

แท็บคือ Essential, Basic, Lists, Media & Code และ Advanced ส่วน Essential เรียงตามความถี่ใช้งานในเครื่อง และมีรายการเริ่มต้นก่อนสะสมประวัติ ใน v0.49.0 ยังไม่ใช่คลัง snippet ที่เพิ่มแม่แบบเองหรือปักหมุดรายการได้

กรอกแต่ละช่อง

สำหรับ Link ให้พิมพ์ข้อความลิงก์ กด Tab กรอก URL แล้ว Tab ออก Shift+Tab ย้อนช่องก่อนหน้า Tab ครั้งสุดท้ายวางเคอร์เซอร์หลังลิงก์หนึ่งช่องว่างเพื่อเขียนประโยคต่อ

Image เริ่มจาก alt text แล้วจึงพาธ Code block เริ่มจากภาษาแล้วจึงตัวโค้ด Table ไล่หัวตารางสองช่องแล้วไปยังเซลล์ของแถวแรก Esc จบการนำทางช่องกรอก แล้ว Esc ถัดไปจึงกลับ PREVIEW หากไม่มีสิ่งอื่นรับปุ่มอยู่

ตัวอย่างที่คัดลอกได้

ด้านล่างเป็นต้นฉบับที่กรอกเสร็จแล้ว คัดลอกไปใช้หรือสร้างโครงสร้างเดียวกันจากเมนูก็ได้ เครื่องหมายอย่าง ${text} เป็นรูปแบบภายในของแม่แบบ ไม่ใช่สิ่งที่ต้องใส่ในเอกสารสุดท้าย

เมื่อ Tab ทำงานต่างออกไป

การนำทางต้องมีช่องกรอกที่ยังใช้งานอยู่ เมื่อกรอกเสร็จหรือยกเลิกแล้ว ข้อความเป็นต้นฉบับปกติ Tab จึงมักกลับไปทำหน้าที่เยื้อง ที่เซลล์สุดท้ายของแถวเนื้อหาสุดท้าย มีคำสั่งตารางอีกส่วนหนึ่งสำหรับเพิ่มแถว อ่านบท ตาราง ก่อนคาดหวังว่า Tab จะเลื่อนทุกเซลล์เหมือนสเปรดชีต

รายการที่แทรกข้อความง่าย ๆ ยังมีหัวข้อ อัญประกาศคัดข้อความ เส้นคั่น รายการ HTML และ comment ส่วน Smart Snippets ที่กำหนดเอง การขยายตัวแปรอิสระ และการแก้ลำดับ Essential เองยังไม่ใช่ฟีเจอร์ของ slash menu รุ่นเผยแพร่

บทก่อนหน้าแก้ไขอย่างแม่นยำบทถัดไปตาราง Markdown
