ติดตั้งและเริ่มใช้งาน

คู่มือรุ่นเผยแพร่: v0.49.0

ในหน้านี้
  • เลือกตัวติดตั้งให้ตรงเครื่อง
  • เปิดเอกสารแรก
  • สัญลักษณ์คีย์ลัดและการอัปเดต

MarkItBetter (MIB) เป็นโปรแกรมแก้ไข Markdown บนเดสก์ท็อปที่เริ่มจากการอ่านเอกสารที่จัดรูปแบบแล้ว เมื่อต้องแก้ไขจึงเข้าไปทำงานกับต้นฉบับ แล้วกลับมาอ่านต่อ ไฟล์ยังคงเป็นข้อความธรรมดา คู่มือนี้เขียนสำหรับคนที่ใช้ Markdown อยู่แล้ว และต้องการเรียนรู้วิธีทำงานของ MIB ให้คล่อง

คำแนะนำสำหรับรุ่นเผยแพร่ในคู่มือนี้อ้างอิง v0.49.0 ส่วน บท Mermaid แยกอธิบายฟีเจอร์ที่อยู่ระหว่างพัฒนา การปรากฏชื่อฟีเจอร์ในคู่มือไม่ได้หมายความว่าโปรแกรมรุ่นที่ติดตั้งอยู่จะมีฟีเจอร์นั้นแล้ว

เลือกตัวติดตั้งให้ตรงเครื่อง

ใช้ไฟล์จากช่องทางดาวน์โหลดหรือช่องทางซื้อที่เป็นทางการ และตรวจทั้งระบบปฏิบัติการกับชนิดหน่วยประมวลผล

เครื่อง ไฟล์ของ v0.49.0
Mac ที่ใช้ Apple Silicon MarkItBetter_aarch64.dmg
Mac ที่ใช้ Intel MarkItBetter_x64.dmg
Windows แบบ x64 MarkItBetter_0.49.0_x64-setup.exe
Windows แบบ ARM64 MarkItBetter_0.49.0_arm64-setup.exe
Debian/Ubuntu แบบ amd64 MarkItBetter_0.49.0_amd64.deb
Debian/Ubuntu แบบ arm64 MarkItBetter_0.49.0_arm64.deb

บน macOS ให้เปิดดิสก์อิมเมจแล้วติดตั้งโปรแกรมใน Applications บน Windows ให้เรียกตัวติดตั้งที่ตรงกับเครื่อง ส่วน Debian/Ubuntu ใช้ตัวจัดการแพ็กเกจ เช่น คำสั่งต่อไปนี้เมื่ออยู่ในโฟลเดอร์ที่ดาวน์โหลดไฟล์ amd64 ไว้

sh
sudo apt install ./MarkItBetter_0.49.0_amd64.deb

เปลี่ยนชื่อไฟล์ให้ตรงกับไฟล์ที่มีจริง หากระบบแจ้งปัญหาการติดตั้งหรือการตรวจสอบ ให้ตรวจแหล่งดาวน์โหลดและสถาปัตยกรรมก่อนลองใหม่ เก็บข้อความผิดพลาดไว้เมื่อต้องขอความช่วยเหลือ

เปิดเอกสารแรก

  1. เปิด MIB การเปิดตามปกติจะแสดงเอกสารต้อนรับใน PREVIEW แต่ถ้าสั่งเปิดไฟล์จากระบบปฏิบัติการ โปรแกรมจะเปิดไฟล์นั้น
  2. เลือก Open File… ปุ่มโฟลเดอร์ หรือ Command+O / Ctrl+O เพื่อเปิดไฟล์ Markdown
  3. อ่านใน PREVIEW และดับเบิลคลิกคำที่ต้องการแก้ไข หรือใช้คีย์บอร์ดตาม เวิร์กโฟลว์ของ MIB
  4. หากเริ่มเอกสารใหม่ ให้เลือก New File จากปุ่มของโปรแกรมหรือ command palette บันทึกเป็นไฟล์จริงก่อนใช้อ้างอิงรูปภาพหรือลิงก์เอกสารแบบสัมพัทธ์

MIB เปิดไฟล์ข้อความ รวมถึงไฟล์โค้ดและ markup ที่พบบ่อยได้ด้วย PDF ไฟล์บีบอัด รูปภาพ และวิดีโอไม่ใช่เอกสารข้อความสำหรับแก้ใน MIB การเปิดรูปเป็นเอกสาร กับการอ้างอิงรูปจาก Markdown เป็นคนละการใช้งาน

สัญลักษณ์คีย์ลัดและการอัปเดต

คู่มือนี้ใช้ Command และ Option สำหรับ Mac โดยคีย์ที่สอดคล้องกันบน Windows/Linux ส่วนมากคือ Ctrl และ Alt ตรวจบริบทและปุ่มทั้งสองแบบได้ใน คู่มือคีย์ลัด ชื่อหน้าจอ เช่น Preferences และ Media & Code คงเป็นภาษาอังกฤษเพื่อให้ตรงกับโปรแกรม

ตรวจรุ่นที่ติดตั้งใน About MarkItBetter ก่อนเทียบพฤติกรรมกับคู่มือ ราคาที่เจ้าของผลิตภัณฑ์ระบุคือ $13 พร้อม อัปเกรดฟรีตลอดอายุการใช้งาน คู่มือนี้ไม่ได้กำหนดระบบสมาชิกหรือขั้นตอนเปิดใช้สิทธิ์เพิ่มเติม สำรองเอกสารและใช้ตัวติดตั้งจากช่องทางทางการเมื่อมีรุ่นใหม่
