# บริการบันทึก

เก็บบันทึกโครงการเป็นไฟล์ Markdown

## เริ่มต้น

1. คัดลอกการตั้งค่าตัวอย่าง
2. ระบุโฟลเดอร์เก็บข้อมูลในเครื่อง
3. เริ่มบริการแล้วตรวจ health endpoint

## คำสั่ง

| งาน | คำสั่ง |
| --- | --- |
| รันการตรวจสอบ | `npm test` |
| เริ่มในเครื่อง | `npm run dev` |

## อ้างอิง

- [การตัดสินใจ](./decisions.md)
- [Configuration](#configuration)

## Configuration

ระบุค่าที่รองรับและตัวอย่างขั้นต่ำที่นี่

คำสั่งข้างต้นเป็นของโครงการสมมติ ไม่ใช่ CLI ของ MIB เปลี่ยนเป็นคำสั่งที่โครงการมีจริง ใช้ Outline ตรวจว่าโครงสร้างเล่าเรื่องเข้าใจก่อนขัดเกลาถ้อยคำ

# ADR: เก็บบันทึกเป็น Markdown

## บริบท

ทีมต้องทบทวนความเปลี่ยนแปลงผ่าน version control และแก้ไขออฟไลน์

## การตัดสินใจ

เก็บหนึ่งบันทึกต่อหนึ่งไฟล์ Markdown ธรรมดา

## ผลที่ตามมา

- เปลี่ยนตัวแก้ไขได้โดยไม่แปลงเนื้อหา
- ต้องตรวจลิงก์สัมพัทธ์เมื่อย้ายไฟล์
- ทีมต้องตกลงส่วนขยายการแสดงผลร่วมกัน

## ตรวจทาน

- [ ] ยืนยันข้อจำกัดกับทีม
- [ ] ลิงก์การสนทนาฝั่ง implementation

เมื่อมีหลายการตัดสินใจ ให้แยกเป็นไฟล์และเชื่อมโยงกัน แทนรวมทุกอย่างในภาพเดียว บท Mermaid มีตัวอย่าง flowchart, sequence, journey และ ER สำหรับเวิร์กโฟลว์ที่กำลังจะรองรับ

เช็กลิสต์เผยแพร่พร้อมหลักฐาน

markdown
# ตรวจสอบก่อนเผยแพร่

- [ ] ยืนยันรุ่นและรายการเปลี่ยนแปลง
- [ ] รันการตรวจสอบของโครงการ
- [ ] บันทึกข้อผิดพลาดและเรื่องค้าง
- [ ] ทบทวนบันทึกสำหรับผู้ใช้
- [ ] ตรวจไฟล์ที่จะส่งมอบ

## ผลตรวจ

| รายการ | ผล | หลักฐาน |
| --- | --- | --- |
| Unit tests | รอตรวจ | เพิ่มรายงานจริง |
| เวิร์กโฟลว์ใช้งาน | รอตรวจ | ระบุรุ่นที่ทดสอบ |

อย่าเปลี่ยน “รอตรวจ” เป็น “ผ่าน” เพียงเพราะมีคำสั่งให้เรียก เปลี่ยนหลังรันจริงเท่านั้น สลับงานจาก PREVIEW โดยคง GFM ปกติในต้นฉบับ และใช้ป๊อปอัปตารางเพิ่มแถวหลักฐานตามจำเป็น

บันทึก API ที่ดูแลต่อได้

ใช้ตารางสรุป method, path และจุดประสงค์ แล้วแยกหัวข้อต่อ endpoint พร้อมตัวอย่าง request, response ที่คาดหวัง เงื่อนไขผิดพลาด และข้อสมมติเวอร์ชัน รายการ Link, Table, Code block และ Collapsible ใน slash menu ช่วยประกอบเอกสาร วาง payload ยาวใน code fence และข้อมูลเสริมใน <details>

ก่อนส่งต่อ ให้บันทึก ดูพรีวิว ตามลิงก์สัมพัทธ์ และลองคำสั่งกับระบบที่อธิบาย MIB จัดรูปแบบบันทึกได้ แต่ไม่ได้ตรวจสัญญาของบริการภายนอกแทนผู้เขียน

บทก่อนหน้ารูปลักษณ์และฟอนต์บทถัดไปคู่มือคีย์ลัด
