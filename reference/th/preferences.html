การตั้งค่า Preferences

คู่มือรุ่นเผยแพร่: v0.49.0

ในหน้านี้
  • หาค่าและเข้าใจการจำกัดตามโหมด
  • Editor
  • Preview
  • Focus และความสบายในการเขียน
  • Tasks
  • Pop-ups
  • Code
  • Color
  • การบันทึกและกู้ค่าตั้ง

เปิด Preferences จากปุ่มเฟือง Command+, / Ctrl+, หรือ command palette แผงอยู่ข้างเอกสาร จึงเห็นผลระหว่างปรับ การตั้งค่าที่อธิบายที่นี่มีผลทันที ไม่ต้องกด Apply แยก

แท็บในรุ่นเผยแพร่คือ Editor, Preview, Focus, Tasks, Pop-ups, Code และ Color โปรแกรมเลือกแท็บเปิดแรกตามโหมดอ่านหรือแก้ไขปัจจุบัน ชื่อในบทนี้ใช้ภาษาอังกฤษตาม UI แม้กำลังอ่านคู่มือไทยหรือญี่ปุ่น

หาค่าและเข้าใจการจำกัดตามโหมด

ใช้ Search settings… กรองจากชื่อหรือคำอธิบาย ล้างคำค้นเพื่อกลับไปหน้าปกติของแท็บ หากไม่เห็นตัวควบคุมเฉพาะทางในผลค้นหา ให้เข้าแท็บนั้นโดยตรง

การปรับ Editor ต้องอยู่ EDIT เพื่อให้เห็นผล การปรับ Preview ต้องอยู่ PREVIEW ด้วยเหตุผลเดียวกัน หากอยู่ผิดโหมดจะมีปุ่ม Switch to Editor mode หรือ Switch to Preview mode ส่วนที่ยังใช้ไม่ได้จึงอาจเป็นเพียงข้อจำกัดตามโหมด

Editor

การตั้งค่า ตัวเลือกหรือช่วง ผลที่เปลี่ยน
Font Family Mono หรือฟอนต์โมโนที่ติดตั้งและใช้งานได้ ฟอนต์ต้นฉบับ ช่วยรักษาแนวเยื้องและ pipe
Font Size 11–20 px ขนาดข้อความ ค่าเริ่มต้น 14 px
Line height 1.2–2.2 ตัวคูณความสูงบรรทัด เริ่มต้น 1.6
Line length limit 0–120 ch ความกว้างคอลัมน์ เริ่มต้น 80 ch; 0 ปิดขีดจำกัด
Soft wrap เปิด/ปิด พับบรรทัดยาวบนหน้าจอ เริ่มต้นเปิด
Indentation 2, 4 หรือ 8 ช่องว่าง ขนาดการเยื้อง เริ่มต้น 4
Bracket completion เปิด/ปิด เติมและพิมพ์ทับวงเล็บหรืออัญประกาศคู่ เริ่มต้นเปิด
Typewriter scrolling เปิด/ปิด รักษาบรรทัดพิมพ์ใกล้กลางหน้าจอ เริ่มต้นเปิด
Highlight current line เปิด/ปิด ลงสีบรรทัดเคอร์เซอร์ เริ่มต้นปิด
Show minimap เปิด/ปิด ภาพรวมเอกสารด้านขวา เริ่มต้นปิด

ตัวเลือกฟอนต์ของ Editor เป็นฟอนต์โมโน ส่วน IBM Plex/Noto ของ Preview แยกกัน การเปลี่ยนฟอนต์พรีวิวไม่เปลี่ยนฟอนต์ต้นฉบับ

Soft wrap กับ Line length limit ทำงานเชื่อมกัน ปิด wrap จะทำให้ขีดจำกัดที่ใช้อยู่เป็นศูนย์และเลื่อนบรรทัดยาวแนวนอนได้ เปิดกลับจะคืนคอลัมน์ที่จำไว้ ตั้งขีดจำกัดเป็นค่าบวกจะเปิด wrap ส่วนศูนย์จะปิด ทั้งคู่เป็นการเลือก layout ที่เกี่ยวข้องกัน Soft wrap ไม่แทรก newline ในข้อความที่บันทึก

เมื่อพิมพ์ไทยหรือญี่ปุ่น เริ่มจาก line height 1.6 แล้วเพิ่มหากวรรณยุกต์หรือข้อความผสมยังแน่น ตัวเลขนี้คูณกับขนาดฟอนต์ปัจจุบัน อย่าเพิ่มฟอนต์แล้วกำหนดความสูงคงที่เล็กจนข้อความเบียดกัน

Preview

ตัวควบคุม จุดประสงค์
Match system appearance ให้ธีมเอกสารตามโหมดสว่าง/มืดที่ระบบสรุปใช้อยู่
Theme เลือกธีมโดยตรง และปิดการตามระบบเมื่อเลือก
Content width Wide (90%) หรือ Centered (60%) แทนกฎอัตโนมัติในช่วงเปิดไฟล์ปัจจุบัน
Font family คู่ฟอนต์พรีวิว IBM Plex หรือ Noto
Body style Serif หรือ Sans ปรากฏเมื่อใช้ Noto

เปิดไฟล์อื่นเพื่อคืนความกว้างอัตโนมัติ หากตัวเลือกเหมือนรีเซ็ต ให้ตรวจว่าเพิ่งเปลี่ยนเอกสารหรือไม่ ความกว้างนี้ไม่ใช่ค่าถาวรทั่วทั้งโปรแกรม

IBM Plex เป็นจุดเริ่มต้นที่ตรงไปตรงมาสำหรับการอ่านไทยแบบมีหัว ตัวเลือก Noto มีลักษณะต่างกัน ให้ตรวจย่อหน้าจริงก่อนเลือก นโยบายฟอนต์ของเว็บคู่มือนี้ไม่ได้เพิ่มตัวควบคุมใหม่ใน MIB

Focus และความสบายในการเขียน

Focus mode ทำให้ข้อความนอกขอบเขตที่กำลังแก้จางลง เปิดปิดด้วย F8 หรือ Preferences Focus scope เลือก Line หรือ Paragraph โดยเริ่มต้นเป็น Paragraph ส่วน Dimmed text opacity มีช่วง 10%–90% เริ่มต้น 40% ค่ายิ่งสูงยิ่งเห็นข้อความรอบข้างชัด

Focus แยกจาก Highlight current line จะคงบริบทรอบข้างโดยไม่ลงสีบรรทัด หรือใช้สีโดยไม่ทำให้ข้อความอื่นจางมากก็ได้ Typewriter scrolling แยกอีกส่วน ทำหน้าที่วางเคอร์เซอร์ในพื้นที่มอง ไม่ได้กำหนดว่าข้อความใดจาง ปรับทีละค่าเพื่อเห็นสาเหตุของผลลัพธ์

Tasks

Strike through completed tasks และ Fade completed tasks มีผลทั้ง EDIT และ PREVIEW และเริ่มต้นเปิดทั้งคู่ การปิดไม่ได้ยกเลิกเครื่องหมายเสร็จหรือเอา marker ออกจากต้นฉบับ เหมาะเมื่อรายการที่ทำเสร็จยังมีประโยชน์สำหรับอ่านอ้างอิง

Pop-ups

Pop-up opacity มีผลกับ slash menu เมนูคลิกขวา และป๊อปอัปตาราง ช่วง 30%–100% เริ่มต้นทึบเต็ม 100% เพิ่มความทึบเมื่อข้อความด้านหลังรบกวนการอ่าน ค่านี้ไม่ใช่ความโปร่งใสของเอกสาร

Code

Code colours เลือก One (Dark / Light) หรือ GitHub (Dark / Light) สำหรับ fenced code ใน PREVIEW โดย appearance เลือกรุ่นสว่างหรือมืดของชุดนั้น พื้นหลังบล็อกยังเกี่ยวข้องกับธีมเอกสาร ภาษาที่ไม่รู้จักอาจยังเป็นโค้ดธรรมดาแม้เลือกชุดสีแล้ว

Color

แท็บ Color รวมสี Editor สีไวยากรณ์ สี Preview และ CSS ของพรีวิว ส่วน Editor ต้องอยู่ EDIT ส่วน Preview ต้องอยู่ PREVIEW ปรับทีละไม่กี่สี แล้วตรวจข้อความ การเลือก ลิงก์ โค้ด และงานที่เสร็จก่อนถือว่าสไตล์พร้อมใช้

การแก้สี built-in สร้างรุ่น (Custom) แทนการเขียนทับธีมเดิม ใช้ Save Style… และ Load Style… รับส่งไฟล์ .mib_style โดยแยก Editor กับ Preview เก็บไฟล์ที่ export ไว้กับบันทึกโครงการหากต้องการสำเนากู้คืน

สำหรับ CSS ใช้ Download Starter CSS Template แก้ selector ที่รองรับ แล้ว Load CSS… ใช้ Clear CSS เอาค่าทับออก CSS ที่โหลดมีผลหลังธีม จึงอาจเป็นเหตุที่เปลี่ยน picker แล้วไม่เห็นผล ดูตัวอย่างเล็ก ๆ ใน รูปลักษณ์

การบันทึกและกู้ค่าตั้ง

ค่าจำนวนมากบันทึกในเครื่องเมื่อปรับ ไม่ได้ถูกเขียนเป็น metadata ลง Markdown ทุกไฟล์ ความกว้าง Preview เป็นข้อยกเว้นแบบต่อช่วงเปิดไฟล์ตามที่อธิบาย รุ่นเผยแพร่ส่วนนี้ไม่มีขั้นตอนซิงก์ผ่านบัญชี

หากสไตล์กำหนดเองอ่านยาก ให้เลือกธีม built-in ล้าง CSS ที่ยังใช้อยู่ และตรวจค่าของโหมดนั้น Export สไตล์ที่ใช้งานได้ก่อนทดลอง ไม่ควรลบข้อมูลเก็บของแอปเพียงเพื่อแก้สีหรือความกว้างจุดเดียว

บทก่อนหน้าพรีวิวกับต้นฉบับบทถัดไปรูปลักษณ์และฟอนต์
