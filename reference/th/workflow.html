เวิร์กโฟลว์ของ MIB

คู่มือรุ่นเผยแพร่: v0.49.0

ในหน้านี้
  • เข้าไปแก้ต้นฉบับตรงตำแหน่งที่ต้องการ
  • กลับมาอ่าน
  • เข้าใจการบันทึก
  • ลองทำงานครบหนึ่งรอบ

PREVIEW ใช้อ่านเอกสาร ส่วน EDIT แสดงต้นฉบับ Markdown คุณจึงแก้เพียงประโยคที่ต้องการแล้วกลับมาอ่านต่อได้ โดยไม่จำเป็นต้องอยู่ในตัวแก้ไขตลอดเวลา

เข้าไปแก้ต้นฉบับตรงตำแหน่งที่ต้องการ

เมื่อต้องแก้เฉพาะจุด ให้ ดับเบิลคลิกคำใน PREVIEW โปรแกรมจะเข้า EDIT และเลือกคำที่สอดคล้องกันในต้นฉบับ หากดับเบิลคลิกช่องว่าง เคอร์เซอร์จะอยู่ใกล้คำก่อนหน้า วิธีนี้ช่วยเมื่อลิงก์ รายการ หรือย่อหน้ามีเครื่องหมาย Markdown ที่มองไม่เห็นในผลลัพธ์

พฤติกรรมคีย์บอร์ดในพรีวิวของรุ่นเผยแพร่มีรายละเอียดดังนี้

การใช้งานใน PREVIEW ผลลัพธ์
เลือกข้อความแล้วกด i เข้า EDIT หลังตำแหน่งต้นฉบับของข้อความที่เลือก
กด i โดยไม่มีข้อความที่เลือกซึ่งใช้ระบุตำแหน่งได้ เข้า EDIT ที่ท้ายเอกสาร
กด a เข้า EDIT ที่ท้ายเอกสาร
เลือก Switch to EDIT จาก command palette กลับไปยังเคอร์เซอร์หรือช่วงเลือกเดิมของตัวแก้ไข

หากตำแหน่งต้องแม่นยำ ให้ดับเบิลคลิกคำที่จะเปลี่ยน ไม่ต้องเดาหมายเลขบรรทัดจากหน้าพรีวิว

กลับมาอ่าน

กด Esc จาก EDIT ตามปกติเพื่อบันทึกเอกสารที่มีพาธแล้ว และกลับไป PREVIEW ใกล้บล็อกที่เคอร์เซอร์อยู่

Esc จะจัดการสิ่งที่กำลังใช้งานอยู่ก่อน เช่น ปิด slash menu จบการเลื่อนช่องกรอกของ snippet หรือปิดแผงค้นหา เมื่อจบการใช้งานนั้นแล้วจึงกด Esc อีกครั้งเพื่อกลับไปอ่าน ดูลำดับเฉพาะได้ในบท Snippet และ การนำทาง

เข้าใจการบันทึก

ไฟล์ที่มีชื่อและพาธแล้วจะถูกบันทึกหลังหยุดพิมพ์สามวินาที เมื่อออกจาก EDIT ไป PREVIEW และเมื่อหน้าต่างที่ใช้แก้ไขเสียโฟกัส Command+S / Ctrl+S ยังมีประโยชน์ก่อนย้ายหรือส่งต่อไฟล์

เอกสารที่ยังไม่มีชื่อจะอยู่ในหน่วยความจำจนกว่าจะเลือกตำแหน่งบันทึก ใช้ Save As… หรือคีย์บันทึกแล้วดำเนินการในหน้าต่างเลือกไฟล์ให้เสร็จ การสลับโหมดจะไม่ตั้งชื่อไฟล์ให้เอง เมื่อปิดเอกสารที่ยังไม่บันทึกจะมีตัวเลือกบันทึก ไม่บันทึก หรือยกเลิก หากบันทึกไม่สำเร็จ ควรเก็บข้อความไว้จนกว่าจะมีสำเนาที่ตรวจสอบได้

# บันทึกการเผยแพร่

เริ่มจากความต้องการของผู้อ่าน

- [ ] ตรวจตัวอย่าง
- [ ] ทบทวนถ้อยคำ

กลับไป PREVIEW ดับเบิลคลิกคำที่ต้องการแก้ เปลี่ยนข้อความ แล้วกด Esc ตรวจทั้งผลลัพธ์และข้อความที่บันทึก จากนั้นลองคลิกงานใน PREVIEW โปรแกรมจะเปลี่ยนเครื่องหมาย [ ] / [x] ในต้นฉบับจริง

สำหรับการเขียนนาน ๆ ใช้ Focus และ Typewriter ปรับสภาพแวดล้อมการทำงานได้ โดยเนื้อหาในไฟล์ยังเป็น Markdown ที่นำไปใช้กับโปรแกรมอื่นได้

บทก่อนหน้าติดตั้งและเริ่มใช้บทถัดไปไฟล์และโฟลเดอร์

ต้นฉบับ Markdown
