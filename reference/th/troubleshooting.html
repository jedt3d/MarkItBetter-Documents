แก้ปัญหาและตรวจสถานะฟีเจอร์

คู่มือรุ่นเผยแพร่: v0.49.0

ในหน้านี้
  • ปุ่มทำสิ่งที่ไม่คาดคิด
  • เปิดหรือบันทึกไฟล์ไม่ได้
  • รูปหรือลิงก์ในเครื่องไม่แสดง
  • ข้อความเบียดหรือค่าตั้งไม่เกิดผล
  • โค้ดยังไม่มีสี
  • รุ่นเผยแพร่กับฟีเจอร์ที่จะตามมา
  • เตรียมรายงานที่ตรวจต่อได้

เริ่มจากรุ่นโปรแกรม โหมด และตัวอย่างเล็ก ๆ รายงานว่า “v0.49.0 ใน EDIT หลังแทรก Link snippet” ช่วยตรวจปัญหาได้มากกว่า “คีย์บอร์ดไม่ทำงาน”

ปุ่มทำสิ่งที่ไม่คาดคิด

ปิดเมนูหรือการค้นหาที่ใช้อยู่ แล้วลองโดยให้เอกสารมีโฟกัส Esc อาจจบ snippet ก่อนกลับ PREVIEW และ Tab อาจเยื้องหลังจบช่องกรอก i ใน PREVIEW ใช้ช่วงเลือกเมื่อทำได้ มิฉะนั้นจะเพิ่มท้ายเอกสาร ใช้ดับเบิลคลิกเมื่อต้องแก้คำให้ตรงจุด

ตรวจ คีย์ตามบริบท การรับปุ่ม modifier ของระบบ และสถานะ IME เก็บตัวอย่างก่อนลอง Replace All ซ้ำหรือแก้โครงสร้างขนาดใหญ่

เปิดหรือบันทึกไฟล์ไม่ได้

ตรวจว่าเป็นไฟล์ข้อความและเขียนปลายทางได้ อย่าเปิดรูป PDF ไฟล์บีบอัด หรือวิดีโอเป็น Markdown เอกสารไม่มีชื่อจำเป็นต้องเลือก Save As หากไฟล์ถูกย้ายหรือลบนอก MIB ให้ตรวจพาธจริงก่อนบันทึก

เก็บตัวแก้ไขไว้เมื่อบันทึกผิดพลาด คัดลอกข้อความสำคัญไปที่ปลอดภัย เก็บข้อความ error และอย่าทิ้ง buffer จนยืนยันสำเนาแล้ว หลังบันทึกสำเร็จอาจเปิดสำเนาเพื่อตรวจสิ่งที่อยู่บนดิสก์

รูปหรือลิงก์ในเครื่องไม่แสดง

บันทึกเอกสารไว้ในโครงการจริง เก็บไฟล์อ้างอิงในโฟลเดอร์เดียวกันหรือย่อย และตรวจตัวพิมพ์ชื่อไฟล์กับไวยากรณ์ พาธสัมพัทธ์ขึ้นกับโฟลเดอร์เอกสาร หากเพิ่ง Save As แล้วรูปยังไม่แสดง ให้เปิดเอกสารใหม่

ขอบเขตเข้าถึงรูปของรุ่นเผยแพร่อาจปฏิเสธพาธที่ออกนอกโฟลเดอร์ สำหรับรายงาน ให้ทำโฟลเดอร์เล็กที่มี .md และไฟล์ตัวอย่างไม่เป็นความลับ โดยใช้พาธง่าย ๆ ไม่ต้องส่งทั้งโครงการส่วนตัวเพื่ออธิบายลิงก์เสีย

ข้อความเบียดหรือค่าตั้งไม่เกิดผล

ตรวจข้อจำกัดตามโหมดใน Preferences Line height ของ Editor กับ CSS ของ Preview เป็นคนละส่วน ลองบรรทัดไทย/ญี่ปุ่นจริงหลังเปลี่ยนฟอนต์ และไม่กำหนดความสูงคงที่เล็กกว่าตัวอักษร

CSS ที่โหลดอาจทับ picker ให้ Clear CSS ตรวจ baseline ก่อนคืนกฎที่ต้องการ หากความกว้างรีเซ็ตหลังเปลี่ยนไฟล์ นั่นเป็นพฤติกรรม session override ถ้าธีมเอกสารคงที่ไม่ตามปุ่ม system/light/dark ให้ตรวจ Match system appearance

โค้ดยังไม่มีสี

ตรวจชื่อภาษาของ fence ภาษาไม่รู้จักจะแสดงเป็นโค้ดธรรมดาโดยตั้งใจ และสีของภาษาที่รองรับอาจตามหลังพรีวิวหลัก เลือกชุดสีใน Preferences → Code ส่วน script และ widget ที่ทำงานเองยังถูกจำกัดแม้ Markdown รอบข้างถูกต้อง

รุ่นเผยแพร่กับฟีเจอร์ที่จะตามมา

สถานะ สิ่งที่คาดหวังได้
เผยแพร่ v0.49.0 PREVIEW/EDIT ไฟล์ข้อความ Favorites/Files Quick Open/Outline/palette ช่อง snippet ตาราง Markdown ที่รองรับ Preferences และสไตล์
งาน Mermaid ที่ตรวจทานแล้ว กรอบกึ่งกลาง Source มีสีไวยากรณ์ ขยายพื้นที่แอป ตระกูลแผนภาพและตัวอักษรหลายภาษา ยังไม่มีใน v0.49.0
Viewer รอบถัดไป Fit All, zoom/pan และปุ่มที่แสดงเมื่อ hover ยังปรับอยู่ พร้อมงานรวมระบบและตรวจรับที่ยังค้าง
นอกขอบเขตรุ่นเผยแพร่ Smart Snippets กำหนดเอง ส่วนขยาย Mermaid อิสระ wiki-link/callout/math และฟีเจอร์ที่ยังไม่ประกาศ

การเห็น Mermaid เป็นโค้ดใน v0.49.0 เป็นสิ่งที่คาดไว้ อ่าน บท Mermaid เพื่อเตรียมเนื้อหาและตรวจความเข้ากันได้ แล้วดู release notes จริงก่อนถือว่าฟีเจอร์ที่จะตามมาติดตั้งอยู่แล้ว

เตรียมรายงานที่ตรวจต่อได้

ระบุรุ่น OS สถาปัตยกรรม โหมด ขั้นตอน ผลที่คาด ผลจริง และ error ที่มองเห็น ลดต้นฉบับให้เล็กที่สุดที่ยังทำให้เกิดปัญหา หากเป็น typography ให้คงตัวอักษรและ preset จริง หากเป็นแผนภาพ ให้คง fence กับค่าตั้งตรงตามต้นฉบับ

ใช้ช่องทางช่วยเหลือทางการ และลบข้อมูลลับ พาธส่วนตัว token และเนื้อหาเอกสารส่วนตัวจากตัวอย่าง อัปเดตผ่านช่องทางทางการเมื่อมีรุ่นแก้ปัญหา แล้วลองตัวอย่างเล็กอันเดิมอีกครั้ง
